/authorize と /token の検証を確認します。外部 IdP への試験は、合意した診断範囲内に限定します。

クライアントを診断する

/callback、セッション管理、トークン使用前の検証を確認します。PKCE があっても verifier の使い回しを別途確認します。

リクエストを選び、値を一つだけ変える

画面の成功・失敗だけで判定しない

ID トークンの署名を検証していない場合

認可コードフローでトークンエンドポイントから直接取得する ID トークンは、TLS のサーバー検証で発行者の検証を代替できるため、署名を検証しないことだけでは不備にしません。ブラウザ経由の ID トークンには署名検証が必要です。iss・aud・exp と、送信した nonce の照合は別途必要です。
